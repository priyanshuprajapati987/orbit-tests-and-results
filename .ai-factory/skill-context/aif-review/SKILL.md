## Rules

### Import Completeness Check
**Source:** 2026-08-25-01.missing-imports.md
**Rule:** For every React component review, grep for `Fi[A-Z]` usage in JSX and verify each has a matching import. Also check third-party imports: `toast` from react-hot-toast needs `{ Toaster }` if Toaster is rendered. Missing imports = runtime crash.

### Empty Catch Block Detection
**Source:** 2026-08-25-02.empty-catch-blocks.md
**Rule:** Grep for `catch\s*\{\s*\}` and `catch\s*\([^)]*\)\s*\{\s*\}` in all React components. Every empty catch is a finding. Minimum acceptable: `catch (e) { console.error(...) }`. For API calls: `catch (e) { toast.error(...) }`.

### Orphaned Import Scan
**Source:** 2026-08-23-01.orphaned-imports.md
**Rule:** After any module deletion or rename, run `grep -r "from.*deleted_module"` across the codebase. Check: blueprint registrations, config imports, test imports, __init__.py re-exports. One orphaned import crashes server startup.

### Flask Endpoint Audit
**Source:** 2026-08-25-03.voice-endpoint-crashes.md
**Rule:** For every `@blueprint.route` handler, verify: (1) has try/except, (2) uses `get_json(silent=True) or {}` not `get_json(force=True)`, (3) has `logger.exception()` on catch, (4) returns structured JSON error with 500 status. Missing any = production 500 trace leak.

### Panel State Management Audit
**Source:** 2026-08-25-04.panel-registration-gaps.md
**Rule:** When reviewing new panel additions, verify the panel appears in ALL FOUR locations: state declaration, JSX render tree, `anyPanelOpen()` function, `closeActivePanel()` function. Missing any = broken close button or state leak.

### Hardcoded Color Detection
**Source:** 2026-08-25-05.hardcoded-colors.md
**Rule:** Search for hardcoded color values in inline styles: `#[0-9a-f]{3,8}`, `rgb(`, `rgba(`. These should use `var(--orbit-*)` CSS variables. Exception: color values passed as props to charting libraries.

### Python Silent Catch Detection
**Source:** 2026-08-23-02.silent-error-swallowing.md
**Rule:** Grep for `except.*:\s*pass` in Python files. Every instance is a finding — errors are invisible. Replace with at least `logger.debug()`. Use `logger.exception()` for unexpected errors.

### Security Stub Detection
**Source:** 2026-08-23-03.fake-security-responses.md
**Rule:** In security-related functions (auth, encryption, key rotation, session management), check if the function returns a success response without actually performing the action. Stubs must be clearly marked with `{"status": "stub", ...}` and a WARNING log.

### React Hook Order Check
**Source:** 2026-08-27-01.tdz-violation.md
**Rule:** In React components, verify that `useCallback`/`useEffect` hooks reference variables declared ABOVE them. If hook A uses `functionB`, `functionB` must appear earlier in the file. The TDZ error message names the variable.

### Thread Safety on Shared Files
**Source:** session audit 2026-08-31 (llm_audit.py JSONL corruption)
**Rule:** For append-only file logs (JSONL, audit trails) accessed from Flask request threads, use `threading.Lock` or `threading.RLock`. Concurrent `open().write()` + `json.dump()` without locks causes corrupted JSON lines. Always wrap the open-dump-close sequence in a lock.

### React Cleanup Function Audit
**Source:** session audit 2026-08-31 (streaming reader unmount leak)
**Rule:** For React useEffect that creates subscriptions, streams, or timers: verify the cleanup function cancels/stops/disposes all of them. Missing cleanup = memory leak. Specifically: `reader.cancel()` for ReadableStream, `clearInterval`/`clearTimeout` for timers, `eventSource.close()` for SSE, `unsubscribe()` for observables.

### Null Guard on Array Methods
**Source:** session audit 2026-08-31 (Sidebar messages.reduce crash)
**Rule:** For any array method (`.reduce()`, `.map()`, `.filter()`, `.find()`) on state that may be undefined/null on first render or during loading, add a null guard: `(items || []).method(...)`. This catches race conditions where data hasn't loaded yet.

### SSE Payload Completeness
**Source:** session audit 2026-08-31 (router reasoning_content missing)
**Rule:** When parsing streaming responses (SSE, WebSocket), check ALL known payload fields in the delta/chunk — not just the primary `content` field. Missing fields (like `reasoning_content`) silently drop data. List all expected fields and verify each is handled in the parser.

### Import Completeness for Type Annotations
**Source:** session audit 2026-08-31 (CodeAgent List import)
**Rule:** After adding type annotations to function signatures, verify all `typing` imports exist. `List[str]` without `from typing import List` = NameError at call time. Grep for `[A-Z][a-z]*` in annotations and cross-check imports.

### Variable Initialization Before try
**Source:** session audit 2026-08-31 (conversation_engine context_block)
**Rule:** If a variable is referenced in an `except` block, it must be assigned before the `try` or initialized to None/empty at function start. Variables set only inside `try` are unbound if an earlier statement throws.

### Shell Injection Grep
**Source:** session audit 2026-08-31 (ComputerTool PS metacharacters)
**Rule:** Grep for raw string interpolation in shell/subprocess commands: `f"...{user_input}..."`, `"...".format(...)`, `"..."+var+"..."` in calls to `subprocess.run`, `os.system`, `os.popen`, or `run_command`. These are injection vectors — require escaping or parameterized execution.

### Gate Return Value Audit
**Source:** session audit 2026-08-31 (5 agents _get_tool() None)
**Rule:** For `if self.X:` or `if self.assistant:` patterns in methods that return a tool/capability, verify the method returns something useful when the condition is False. Silently returning None propagates through the call stack and causes confusing downstream errors.

### Streaming Parameter Parity
**Source:** session audit 2026-08-31 (router stream vs generate)
**Rule:** When reviewing code with multiple output paths (generate vs stream_generate, sync vs async), diff the parameter handling of each path. Missing system_prompt, missing reasoning_content, or missing category in one path = silent data loss or degraded output.
