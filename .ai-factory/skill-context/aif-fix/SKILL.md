## Rules

### Import Verification First
**Source:** 2026-08-25-01.missing-imports.md
**Rule:** When a React component crashes with "X is not defined" or "X is not a function", the FIRST check should be the import block — not component logic. Verify every `Fi*` icon, every third-party component (toast, motion, etc.) has a corresponding import at the top of the file.

### Empty Catch Block Anti-Pattern
**Source:** 2026-08-25-02.empty-catch-blocks.md
**Rule:** NEVER write `catch {}` or `catch (e) {}` in React components. At minimum add `console.error('ComponentName:', e)` or `toast.error('Action failed')`. For API calls, show user-facing error feedback. Grep for `catch\s*\{\s*\}` during review.

### Orphaned Import Detection
**Source:** 2026-08-23-01.orphaned-imports.md
**Rule:** When deleting a Python module, search for ALL import references across the codebase before committing. Use `grep -r "from.*deleted_module"` — check blueprints, config, and test files. A deleted module imported by server.py crashes the entire Flask app.

### Flask Endpoint Error Handling Template
**Source:** 2026-08-25-03.voice-endpoint-crashes.md
**Rule:** Every Flask endpoint MUST have: (1) try/except wrapping the body, (2) `get_json(silent=True) or {}`, (3) `logger.exception()` on catch, (4) structured JSON error response with 500 status. Use this template:
```python
@bp.route("/api/endpoint")
def endpoint():
    try:
        data = request.get_json(silent=True) or {}
        return jsonify(result)
    except Exception as e:
        logger.exception("endpoint failed")
        return jsonify({"error": "description"}), 500
```

### Silent Error Swallowing in Python
**Source:** 2026-08-23-02.silent-error-swallowing.md
**Rule:** NEVER write `except Exception: pass` in Python. At minimum use `except Exception as exc: logger.debug("Component failed: %s", exc)`. For user-facing features use `logger.warning()` or `logger.exception()`.

### Fake Security Response Detection
**Source:** 2026-08-23-03.fake-security-responses.md
**Rule:** When fixing security-related functions, check if they return fake success responses. Stubs MUST return `{"status": "stub", "action": "name", "message": "not yet implemented"}` with a WARNING log — never fake success codes.

### Temporal Dead Zone in React
**Source:** 2026-08-27-01.tdz-violation.md
**Rule:** In React components, order hooks so dependencies are declared BEFORE dependents. If hook A uses `functionB`, then `functionB` must be declared BEFORE hook A. The error "Cannot access 'X' before initialization" directly names the problematic variable.

### Panel Registration Completeness
**Source:** 2026-08-25-04.panel-registration-gaps.md
**Rule:** When a panel's close button doesn't work, check if it's registered in BOTH `anyPanelOpen()` AND `closeActivePanel()`. Every new panel needs 4 things: state variable, JSX render, anyPanelOpen entry, closeActivePanel entry.

### Hardcoded Color Detection
**Source:** 2026-08-25-05.hardcoded-colors.md
**Rule:** Search for hardcoded color values (`#[0-9a-f]{3,8}`, `rgb(`, `rgba(`) in inline styles of React components. Replace with `var(--orbit-*)` CSS custom properties. Available tokens: `--orbit-bg`, `--orbit-surface`, `--orbit-surface-hover`, `--orbit-border`, `--orbit-text`, `--orbit-text-secondary`, `--orbit-header-bg`. Hardcoded colors break light mode.

### Variable Scope in try/except
**Source:** session audit 2026-08-31 (conversation_engine context_block NameError)
**Rule:** When a variable is used in both the `try` block AND the `except` block, ensure it is initialized BEFORE the `try` or at the start of the function. Variables set only inside `try` are unbound if an earlier statement in `try` throws. Add `var = None` before the try block as a safety net.

### Shell Metacharacter Escaping
**Source:** session audit 2026-08-31 (ComputerTool PS injection)
**Rule:** When building shell command strings from user input, escape ALL shell metacharacters for the target shell. PowerShell: `;`, `|`, `&`, `` ` ``, `$()` are injection vectors. Use `shlex.quote()` or manual backtick escaping. Never interpolate raw user input into command strings.

### Resource Cleanup on Partial Failure
**Source:** session audit 2026-08-31 (BrowserTool resource leak)
**Rule:** When acquiring resources in a `try` block (browser contexts, file handles, connections), wrap in `try/finally` or use a context manager. If `__init__` or setup fails partway, the partially-created resources must be cleaned up. Never leave dangling resources on exception — call `self.close()` in the except block before re-raising.
