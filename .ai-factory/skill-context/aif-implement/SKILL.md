## Rules

### Icon Import Checklist
**Source:** 2026-08-25-01.missing-imports.md
**Rule:** When adding new `react-icons/fi` usage in a component, verify the icon exists in the import block. Search for all `Fi*` references in the file and cross-reference with the import statement. Missing imports cause runtime crashes.

### Never Write Empty Catch Blocks
**Source:** 2026-08-25-02.empty-catch-blocks.md
**Rule:** NEVER write `catch {}` or `catch (e) {}` in React. At minimum: `catch (e) { console.error('Context:', e) }`. For API calls add `toast.error('Failed to load')`. Empty catches make bugs invisible.

### Module Deletion Cleanup
**Source:** 2026-08-23-01.orphaned-imports.md
**Rule:** When deleting a module, search ALL import references before committing: `grep -r "from.*module_name"` across the entire codebase. Remove imports from: blueprints, config, test files, __init__.py. A single orphaned import can crash server startup.

### Flask Endpoint Template
**Source:** 2026-08-25-03.voice-endpoint-crashes.md
**Rule:** Every new Flask endpoint MUST use this template:
```python
@bp.route("/api/name", methods=["POST"])
def name():
    try:
        data = request.get_json(silent=True) or {}
        # validate input
        if not data.get("required_field"):
            return jsonify({"error": "required_field missing"}), 400
        # business logic
        result = do_work(data)
        return jsonify(result)
    except Exception as e:
        logger.exception("name failed")
        return jsonify({"error": "description"}), 500
```

### Panel Registration Checklist

**Rule:** When adding a new panel, ALL FOUR must be updated: (1) state variable `const [xOpen, setXOpen] = useState(false)`, (2) JSX render `{xOpen && <XPanel onClose={() => setXOpen(false)} />}`, (3) `anyPanelOpen()` function includes `xOpen`, (4) `closeActivePanel()` includes `setXOpen(false)`.

### CSS Variables Only
**Source:** 2026-08-25-05.hardcoded-colors.md
**Rule:** NEVER use hardcoded color values in inline styles. Always use `var(--orbit-*)` CSS custom properties. Available tokens: `--orbit-bg`, `--orbit-surface`, `--orbit-surface-hover`, `--orbit-border`, `--orbit-text`, `--orbit-text-secondary`, `--orbit-header-bg`. Hardcoded colors break light mode.

### Hook Ordering in React
**Source:** 2026-08-27-01.tdz-violation.md
**Rule:** In React components, order hooks so dependencies are declared BEFORE dependents. If `useCallback` A references `functionB`, then `functionB` must be declared ABOVE hook A. The error "Cannot access 'X' before initialization" tells you which variable is the problem.

### Python Error Handling
**Source:** 2026-08-23-02.silent-error-swallowing.md
**Rule:** NEVER write `except Exception: pass` in Python. Use: `except Exception as exc: logger.debug("Context: %s", exc)` for expected fallbacks, `logger.exception()` for unexpected errors. Silent catches make debugging impossible.

### Security Stub Pattern
**Source:** 2026-08-23-03.fake-security-responses.md
**Rule:** When creating stub functions for security features, ALWAYS return `{"status": "stub", "action": "name", "message": "not yet implemented"}` with a WARNING log. Never return fake success responses — they are indistinguishable from real success in audits.

### Type Annotation Import Check
**Source:** session audit 2026-08-31 (CodeAgent List[str] NameError)
**Rule:** Before using any type annotation (`List`, `Dict`, `Optional`, `Tuple`, `Set`), verify the import exists. Python <3.10 requires `from typing import X`. After adding annotations, grep used type names vs import block. Missing import = NameError at call time, not definition time.

### Optional Gate Handling
**Source:** session audit 2026-08-31 (5 agents _get_tool() returning None)
**Rule:** When writing initialization gates (`if self.X:`), verify X is always set in `__init__`. If X is optional, the gate must handle the None case explicitly — return a default tool, raise an error, or log a warning. Never let a gate silently return None and leave downstream callers with a missing tool/capability.

### Alternative Path Parity
**Source:** session audit 2026-08-31 (router stream_generate missing system_prompt)
**Rule:** When implementing alternative code paths (streaming vs non-streaming, sync vs async, v1 vs v2), copy ALL parameter defaults from the primary path. Differences between paths should be intentional, not accidental omissions. Diff the parameters of both paths before finalizing. If generate() auto-sets system_prompt, stream_generate() must too.

### Bounded Filesystem Walk
**Source:** session audit 2026-08-31 (file_tools.search() no limit)
**Rule:** When walking filesystems (`os.walk`, `os.scandir`, `Path.rglob`), add a configurable `max_results` cap (default 5000) and/or max directory depth. Unbounded walks on large trees cause OOM or timeout. Return a warning in results when the cap is hit.
