# Patch: Missing Icon/Component Imports in React

**Date:** 2026-08-25
**Severity:** HIGH
**Tags:** #react #imports #crash #frontend
**Files:** Sidebar.jsx, CommandPalette.jsx, App.jsx

## Problem
Multiple components referenced icons from `react-icons/fi` and components from `react-hot-toast` without importing them. This caused runtime ReferenceError crashes.

- `FiRefreshCw` used in Sidebar.jsx but not imported
- `FiDownload`, `FiShare2` used in CommandPalette.jsx but not imported
- `Toaster` used in App.jsx but only `toast` was imported from `react-hot-toast`

## Root Cause
Adding new UI features without checking the import block. Icons are referenced by name in JSX but the import list was not updated.

## Prevention
- **aif-implement:** When adding new `react-icons/fi` usage, ALWAYS verify the icon exists in the import block at the top of the file. Search for `Fi` prefix usage and cross-reference with imports.
- **aif-review:** Check that every `Fi*` component used in JSX has a corresponding import. Check that every component from third-party libs (react-hot-toast, framer-motion, etc.) is properly destructured in the import.
- **aif-fix:** When a React component crashes with "X is not defined", the FIRST check should be the import block — not component logic.
