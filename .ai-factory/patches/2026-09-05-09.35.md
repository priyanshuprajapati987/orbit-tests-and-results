# Remove 8 pre-existing unused imports from changed files

**Date:** 2026-09-05 09:35
**Files:** orbit/orbit/core/context_manager.py, orbit/orbit/core/circuit_breaker.py, orbit/orbit/core/conversation_engine.py, orbit/orbit/core/policy_engine.py, orbit/orbit/server.py
**Severity:** low

## Problem

8 unused imports (F401) detected in files modified during the audit-fix sprint. While pre-existing, they pollute the namespace and fail lint checks.

## Root Cause

Imports added during initial development that were never used — `Dict`, `USER_NAME`, `TITLE`, `app_root`, `Type`, `field`, `Path` (local), `_time`. The local `from pathlib import Path` inside `_log_audit_entry` was redundant because `self._audit_file.parent` already returns a `Path` object. The `import time as _time` in the health endpoint was never referenced.

## Solution

Removed all 8 unused imports:
- `context_manager.py`: removed `Dict`, `USER_NAME`, `TITLE`, `app_root`
- `circuit_breaker.py`: removed `Type`
- `conversation_engine.py`: removed `field`
- `policy_engine.py`: removed local `from pathlib import Path`
- `server.py`: removed `import time as _time`

## Prevention

- Run `ruff check --select F401` in CI to catch unused imports
- Use `from __future__ import annotations` to avoid type-only imports
- Review import lists during code review
