# Patch: Temporal Dead Zone — Function Used Before Declaration

**Date:** 2026-08-27
**Severity:** HIGH
**Tags:** #javascript #tdz #react #crash
**Files:** App.jsx

## Problem
`regenerateLast` was defined with `useCallback` BEFORE `sendMessage` was declared. Since `useCallback` captures `sendMessage` in its closure, and `sendMessage` was defined later in the file, this caused a Temporal Dead Zone error at runtime.

## Root Cause
JavaScript `const`/`let` declarations are hoisted but not initialized. Using a variable before its declaration line throws `ReferenceError: Cannot access 'X' before initialization`. React component files often have many `useCallback`/`useEffect` hooks that reference each other, making ordering critical.

## Prevention
- **aif-implement:** In React components, order hooks so that dependencies are declared BEFORE dependents. Rule: if hook A uses `functionB`, then `functionB` must be declared BEFORE hook A.
- **aif-review:** When reviewing React components, check that useCallback/useEffect dependencies are declared above them in the file.
- **aif-fix:** Move the dependent hook below its dependencies. The error message "Cannot access 'X' before initialization" directly tells you which variable is the problem.

## Evidence
- Commit `5921e55` — moved `regenerateLast` useCallback after `sendMessage` declaration
