# Patch: Panel Not Registered in anyPanelOpen/closeActivePanel

**Date:** 2026-08-25
**Severity:** MEDIUM
**Tags:** #react #panels #state-management #ui
**Files:** App.jsx

## Problem
7 panels (costOptimizer, financialTracker, aiOrchestrator, screenIntel, moodDetector, smartExecutor, dailyStandup) were rendered in the JSX but NOT included in `anyPanelOpen()` or `closeActivePanel()`. Result: close button didn't work, panel state leaked.

## Root Cause
New panels were added to the render tree but the developer forgot to also add them to the panel state management functions. These functions are separate from the JSX and easy to miss.

## Prevention
- **aif-implement:** When adding a new panel: (1) add state variable, (2) add to JSX render, (3) add to `anyPanelOpen()`, (4) add to `closeActivePanel()`. All 4 steps are required.
- **aif-review:** When reviewing new panel additions, verify the panel appears in ALL FOUR locations: state, render, anyPanelOpen, closeActivePanel.
- **aif-fix:** When a panel's close button doesn't work, check if it's registered in `anyPanelOpen()` and `closeActivePanel()`.

## Evidence
- Commit `9b32309` — added 7 missing panels to anyPanelOpen + closeActivePanel
