# CRITICAL Security Fixes — Path Traversal, SSRF, Command Injection

**Date:** 2026-09-21 15:00
**Files:** _security_utils.py (new), code_generator_bp.py, code_integrator_bp.py, doc_pipeline_bp.py, rag_bp.py, unstructured_bp.py, bugfixer_bp.py, file_organizer_bp.py, firecrawl_bp.py, smart_browser_bp.py, mobile_bp.py
**Severity:** critical

## Problem

10 API endpoints had CRITICAL security vulnerabilities:
- **Path traversal (8 endpoints):** User-controlled `filepath`/`dirpath`/`output_dir`/`scan_path` passed directly to file operations. Attacker could read/write/delete any file on the filesystem.
- **SSRF (2 endpoints):** User-controlled URLs fetched server-side with no scheme/host validation. Attacker could scan internal network, access cloud metadata endpoints.
- **Command injection (1 endpoint):** Mobile command endpoint accepted arbitrary command strings with no allowlist.

## Root Cause

Blueprints were written as thin wrappers around backend engines with no input validation layer. The assumption was that clients (React UI, mobile app) would only send valid inputs — but the API is directly accessible, so any HTTP client can exploit these.

## Solution

Created shared `_security_utils.py` module with:
- `validate_path(path, mutate)` — workspace sandbox enforcement with system directory blocking
- `validate_url(url)` — SSRF prevention (blocks private IPs, internal domains, dangerous schemes)
- `validate_command(command)` — mobile command allowlist
- `sanitize_filepath(path)` — rejects traversal components (`../`)

Applied to all 10 affected endpoints:
- Path mutations (write/save/fix/organize): blocked if outside workspace
- Path reads (load/scan/ingest): blocked if targeting system directories
- URLs: blocked if targeting private networks or non-HTTP schemes
- Commands: blocked if not in allowlist

## Prevention

- Always validate user-provided paths against a sandbox before file operations
- Always validate URLs before server-side fetching (SSRF is a top-10 OWASP risk)
- Always use allowlists for command execution
- Use shared validation utilities to avoid copy-paste gaps
